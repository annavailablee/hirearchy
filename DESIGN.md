* **Potting Soil:** `#4A2E27`
* **Java Brown:** `#231815`

2. **Color Palette Inspiration:** `https://pinterest.com/pin/color-palette-pantone-earthy-blues-browns` (Warm earthy tones paired with deep crimson and soft cerulean blue)

## Vibe
A warm, sophisticated, high-fashion dashboard interface combining the friendly, rounded modular layout of a modern web app with rich, luxurious earthy tones and muted cerulean accents.

## Relevant UI Notes
* **Modular Card Layout:** Adopt the soft, rounded card structure, pill-shaped action buttons, and clear vertical sidebar navigation layout[cite: 1, 3].
* **Background & Canvas:** Use **Transparent Yellow (`#F5EFC6`)** as the primary light background canvas to keep the interface warm and inviting[cite: 2, 3].
* **Card Containers & Sidebar:** Frame main content cards and sidebar using **Cerulean Blue (`#A5BCD6`)** and muted cream surface tints for contrast[cite: 1, 2].
* **Typography & Primary UI Elements:** Use **Java Brown (`#231815`)** for main body text, headers, and icons to avoid stark pure-black text[cite: 1, 2].
* **Interactive Accents & Highlights:** Apply **Sceptre Red (`#4D0E12`)** for primary CTA buttons, active state highlights, and progress gauge accents[cite: 1, 2].
* **Secondary Accents:** Use **Potting Soil (`#4A2E27`)** for hover states, subtle borders, and secondary metric indicators[cite: 1, 2].
